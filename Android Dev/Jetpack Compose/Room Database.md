* Android library that simplifies working with SQLite databases.
* Abstraction layer over SQLite.
* Part of **Android Jetpack** suite.

Adv:
* Ease of use
* Compile time checks: Validates SQL queries during compilation
* Lifecycle awareness
* Provides support for coroutines (async tasks).

Components:
* Entity: Table in db
* Data Access Object: Model for interacting with db
* Database
