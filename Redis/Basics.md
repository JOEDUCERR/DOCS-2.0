* Redis is a fast and open source, in-memory data store often referred to as a **‘data structure server** and widely-used open-source data storage system that keeps data in memory.
* Use cases: real-time analytics, caching and speed related tasks.
* Keywords: In-Memory Storage (Data stored in RAM), Speed, Scalability (Clustering and replication)
* It supports multi type of data structures so it can be used for multiple use cases.
